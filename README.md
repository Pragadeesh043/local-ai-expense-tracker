# Local AI Expense Tracker

Log income and expenses in plain language from a Windows desktop app. Ollama interprets notes locally, SQLite stores the ledger, and the app keeps a separate Excel report up to date.

## Windows quick start

Install Python 3.11 or newer with Tkinter and [Ollama for Windows](https://ollama.com/download/windows). Start Ollama, then run these commands from the project folder in PowerShell.

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
ollama pull qwen3.5:4b
.\.venv\Scripts\python.exe -m expense_tracker.desktop
```

Enter a test note such as `salary 75000 today + cab 490 UPI yesterday + lunch 330 cash yesterday`. The app can save clear notes automatically. If a note needs review, you can edit or remove the extracted entries before saving. Press **Ctrl+Enter** to submit a note.

Use **Settings → Check Ollama** if the model is unavailable. **Manual entry**, browsing the ledger, and common balance and arithmetic questions work with Ollama offline.

## Desktop workflow

| Screen | What you can do |
| --- | --- |
| **Log** | Record multiple expenses and income entries from one note. Turn off automatic saving to review every note, or use **Undo last save** to reverse the most recent batch. |
| **Dashboard** | Choose a month and currency. Review opening balance, income, spending, closing balance, savings rate, and breakdowns by category, merchant, and payment method. |
| **Transactions** | Search recorded entries and edit or delete them. |
| **Ask** | Ask read-only questions such as `Closing balance last month`, `How much did I spend on food last month?`, or `15% of 42500`. The app calculates results from the ledger and displays the relevant period and currency. |
| **Settings** | Check Ollama, import an existing workbook, retry the Excel update, or turn off chart and activity animations. |

Each currency has its own running balance. A month opens with the previous closing balance, even if intervening months had no activity. For example, an opening balance of ₹500 and spending of ₹125 with no new income leaves ₹375 to carry forward. The savings rate uses only that month’s income and spending.

## Ledger and Excel report

| File | Default Windows location |
| --- | --- |
| SQLite ledger | `%LOCALAPPDATA%\Expense Tracker\transactions.sqlite3` |
| Generated Excel report | `%USERPROFILE%\Documents\Expense Tracker\expenses.xlsx` |
| Application log | `%LOCALAPPDATA%\Expense Tracker\app.log` |

- When an `expenses.xlsx` workbook is present in the launch directory, the app can import it once per ledger. Use **Settings → Import existing workbook** or `--import-from PATH` to choose a different source. The import leaves the source file intact.
- Make corrections in **Transactions**. The app regenerates its Excel report with a dashboard, filterable **Expenses** and **Income** sheets, and a **Monthly Summary** with opening balances, net changes, and closing balances by currency.
- When Excel locks the generated report, transactions still save to SQLite. Close the workbook to let the app retry, or use **Settings → Retry Excel update**.

Use `--data DIRECTORY` to choose another ledger folder and `--report PATH` to choose another report file. Keep the import workbook and the report at separate paths.

## Build the Windows executable

```powershell
.\.venv\Scripts\python.exe -m pip install pyinstaller
.\.venv\Scripts\python.exe -m PyInstaller --onefile --windowed --name ExpenseTracker launch_desktop.pyw
```

Open `dist\ExpenseTracker.exe`. The executable still uses your locally installed Ollama and model. When launching the executable outside the project folder, select your existing workbook from **Settings** if you want to import it.

## Command line

The CLI writes directly to its own Excel workbook, independently of the desktop ledger. Use a separate workbook from the report generated by the desktop app.

```powershell
.\.venv\Scripts\python.exe -m expense_tracker check --model qwen3.5:4b
.\.venv\Scripts\python.exe -m expense_tracker add --model qwen3.5:4b "cab 490 UPI yesterday"
.\.venv\Scripts\python.exe -m expense_tracker add-income "salary 75000 today"
.\.venv\Scripts\python.exe -m expense_tracker list -n 5
.\.venv\Scripts\python.exe -m expense_tracker list --income
.\.venv\Scripts\python.exe -m expense_tracker summarize
```

`add` and `add-income` show a preview before saving. Use `-y` to skip confirmation. Use `chat` for interactive entry and start a line with `income ` to record income. The CLI sorts its workbook by date and rebuilds its dashboard after each write. Use `summarize` after editing the workbook by hand.

## Configuration

| Variable | Default | Applies to |
| --- | --- | --- |
| `EXPENSE_MODEL` | Desktop `qwen3.5:4b`, CLI `qwen2.5-coder:1.5b` | Local Ollama model. Use `--model` to override it on commands that accept the flag. |
| `OLLAMA_URL` | `http://localhost:11434` | Ollama endpoint. The desktop app requires a loopback address. |
| `EXPENSE_XLSX` | `expenses.xlsx` | Desktop import source and CLI workbook. The desktop report uses `--report`. |
| `EXPENSE_SHEET` | `Expenses` | Name of the expense sheet for import and CLI writes. |
| `EXPENSE_CURRENCY` | `INR` | Default currency for the desktop app and CLI. |
| `EXPENSE_TIMEOUT` | `120` seconds | Timeout for Ollama requests. |
| `EXPENSE_RETRIES` | `2` | CLI retries for invalid model output. |
| `EXPENSE_SORT` | `desc` | CLI workbook date order. Set `asc` for oldest first. |
| `EXPENSE_TOTALS` | `1` | CLI monthly total rows. Set `0` to omit them. |
